# Site images

- **buzzoff-logo.png**: the original 1024 px app icon. Kept at this URL in case anything external links to it; pages no longer load it.
- **icon-32.png** (favicon), **icon-180.png** (apple-touch-icon), **icon-128.webp** (header logo at 32 CSS px), **icon-512.jpg** (logo in JSON-LD): resized from buzzoff-logo.png.
- **mascot/**: the capybara cutouts from `~/Desktop/buzzoff-marketing-assets/hero`, as WebP at 360 and 720 px wide.
- **moods/**: the five capybara mood faces from the app (`buzzoff-final/assets/mood-faces/*@3x.png`, 168 px), as WebP. Show them at 84 CSS px or smaller.

Resize with `sips` and convert with `cwebp`. Always set width and height on `<img>`.
